파이프라인을 고칠 때 **추측 대신 재기 위한** 스크립트들. 전부 프로젝트 루트에서 실행한다.


## 표기 검토

**`review_score.py <악보.alphatex>`** — 표기 규칙 전수 검사
- 마디 길이 검산(합이 `beats_per_bar * subdivision` 슬롯인가)
- 정렬 규칙 위반(음표·쉼표가 자기 길이의 배수 위치에서 시작하는가)
- 합칠 수 있는 연속 쉼표
- 음길이 분포·타이 개수·쉼표 비중

표기 로직을 건드렸으면 **이걸 먼저 돌려라.** 위반이 0건이어야 한다.

**`review_shortnotes.py <악보.alphatex>`** — "음표 뒤 쉼표" 패턴 집계
검출된 물리적 길이를 그대로 적으면 스타카토가 16분음표+16분쉼표로 쪼개진다. 그 패턴이 몇 개인지 센다. `16 → r.16`이 많으면 흡수가 덜 된 것이다.

## 격자

**`diag_gridfit.py`** — 균일 격자 피팅 프로토타입
"단일 전역 템포 + 위상"을 베이스 스템 온셋에 맞춰보고, 검출된 개별 비트를 등분하는 현재 방식과 정렬 오차를 비교한다. `beats.py`에 들어간 로직의 원형이고, 격자를 다시 손볼 때 실험대로 쓴다.

## 마디 넘김 타이

**`test_carry.py`**, **`test_quantize_cross.py`** — 단위 테스트
마디를 넘는 음이 다음 마디 앞머리에 타이로 이어지는지, `quantize`가 길이를 자르지 않고 보존하는지 확인한다. 실곡에 해당 사례가 없어서 이 테스트가 유일한 검증 수단이다.
