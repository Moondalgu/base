## 영상 속 서비스 상세 분석

### Neural Note (무료 VST/AU 플러그인 — 영상의 심장)
- 정체: Spotify **basic-pitch 모델**을 플러그인으로 포장한 것 — **우리
  파이프라인의 폴백 엔진과 같은 모델 계열이다.** 즉 이 영상의 채보 품질
  상한 ≈ 우리 basic-pitch 경로. 우리는 CREPE 우선 + 자동 폴백이라 우위.
- UI(11:36 보드 실물): 상단 파형 / 하단 MIDI 이중 창, TRANSCRIPTION
  노브 2개(note sensibility·split sensibility = 검출 민감도), **SCALE
  QUANTIZE**(스케일로 피치 스냅 = 우리 diatonic 스냅에 대응), **TIME
  QUANTIZE**(격자 스냅 = 우리 quantize에 대응). 사용자가 노브를 손으로
  돌려 맞춰야 한다 — 우리는 실측 튜닝값이 파이프라인에 박혀 있다.
- 워크플로(9:31~13:07): 파형 드래그 인 → MIDI 자동 표시 → 원곡 트랙과
  나란히 놓고 **동시 재생으로 귀 검증**(12:24 "싱크 맞추고 작업") →
  노트 위치·길이·옥타브 수작업 보정 → DAW로 드래그 아웃.
- 한계(영상에서 관찰): 노트가 원곡보다 길게 나옴(12:47), 시작 위치
  어긋남(12:09), 옥타브 오류(13:07) — 전부 사용자가 손으로 고친다.

### Audacity + OpenVINO Music Separation (무료 스템 분리)
- Effects 메뉴의 AI 카테고리, 2/4스템 분리(5:06~5:47). Demucs 계열의
  OpenVINO 포팅 — 우리 htdemucs와 동급 목적. 드럼·보컬·베이스 분리
  품질을 영상에서도 "깨끗하다"고 평가.

### MuseScore (무료 표기)
- MIDI 드래그&드롭 → 스태프 자동 분리(25:30), 스페이스바 풀밴드 신스
  재생(26:16), 악기 대체 다이얼로그(26:56), 옥타브 단축키 정리(29:12).

## 우리(Lowend)와의 관계

- **이 영상의 30분 수작업 = 우리의 원클릭.** 유튜브 링크 하나로
  분리(Demucs)→채보(CREPE)→악보(alphaTab)→동기 재생까지 자동이고,
  영상에서 수작업하던 옥타브 통일(pc_floor)·길이 양자화·악기 지정이
  전부 파이프라인에 들어 있다. 시청자 니즈("공짜로 밴드 악보")가 곧
  우리 타깃 니즈라는 시장 검증.
- MIDI·MusicXML 내보내기 이미 보유 — "MuseScore로 이어가기" 경로 성립.

## 클론 후보 (베이스 초보 기능 관점)

1. **밴드 악보(멀티 트랙) 뷰** — 영상의 핵심 매력. 우리는 보컬+베이스
   2트랙 — 드럼 리듬 슬래시 트랙·기타(other) 코드 트랙 추가가 로드맵.
   (드럼 채보는 별도 파이프라인 과제 — 백로그 B-3으로.)
2. **"MuseScore로 보내기" 노출 강화** — MusicXML 다운로드가 접힌 패널에
   있음. 영상 시청자층이 원하는 딱 그 버튼. (소품)
3. 파트별 신스 음색(풀밴드 재생) — PlayScore 벤치와 동일 갭. 후속.
4. 마케팅 카피 소재: "이 영상의 4개 도구·30분을 링크 한 줄로."
